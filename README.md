# Fruit Memory

A simple memory card game. Flip cards to find matching pairs of fruits.

## How to Play

1. Open `index.html` in any web browser.
2. Click a card to reveal a fruit.
3. Click a second card to find its match.
4. Matched pairs stay face up. Unmatched cards flip back.
5. Match all 8 pairs to win.

The timer starts on your first click. Try to win with as few moves as possible.

## Controls

- **New Game** — reshuffle the cards and reset moves, pairs, and time.
- **Play Again** — appears after you win. Starts a fresh game.

## Files

- `index.html` — page structure
- `style.css` — colors, layout, and animations
- `script.js` — game logic

## Features

- 4 x 4 grid with 8 fruit pairs
- Move counter, pair counter, and timer
- Smooth card flip animations
- Win screen with confetti
- Works on desktop, tablet, and mobile
- No frameworks or libraries

## Requirements

A modern web browser. Nothing else.
